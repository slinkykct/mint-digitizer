Embroidery Digitizer

Turn a flat logo into embroidery-ready stitch files for Windows, Linux, and ChromeOS.

Download Windows EXE

Why it works

  • Designed for flat black-and-white logo art
  • Generates DST, PES, JEF, and EXP files
  • Runs locally without needing a server subscription
  • Works well for simple logo stitching and proof production

System support

Windows Linux ChromeOS

The native desktop app is recommended for production use. The web shell is best for quick access and offline install support.

Quick install

  1. Download the Windows EXE from the GitHub release.
  2. Run the installer and choose your installation folder.
  3. Open the app and select a flat logo image.
  4. Export your stitch files and send them to your machine.
